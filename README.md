## 💻 How to Run Locally

### Option 1: Direct File Open (Zero Dependencies)
Simply double-click [`index.html`](file:///D:/portfolio/index.html) or right click and open with Chrome, Edge, or Firefox.

### Option 2: Using Node / NPX
From the `D:\portfolio` directory:
```bash
npx serve .
```
Then visit `http://localhost:3000` in your browser.

## 🌐 How to Deploy in 2 Minutes

### Method A: Deploy to Vercel (Recommended)
1. Install the Vercel CLI (or connect GitHub):
   ```bash
   npx vercel
   ```
2. Follow the 3-step prompt — your portfolio will be live at `https://dharanidharan-portfolio.vercel.app`!

### Method B: Deploy to GitHub Pages
1. Create a repository on GitHub named `dharani2006lakshmi-sys.github.io`
2. Push this folder to that repository:
   ```bash
   git init
   git add .
   git commit -m "feat: initial portfolio release"
   git branch -M main
   git remote add origin https://github.com/dharani2006lakshmi-sys/dharani2006lakshmi-sys.github.io.git
   git push -u origin main
   ```
3. Your site will automatically go live at:
   `https://dharani2006lakshmi-sys.github.io`
